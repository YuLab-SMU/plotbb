# plotbb 0.2.0 已实现功能盘点（0.2.5 工作项 1）

依据：`NAMESPACE` 导出、`man/*.Rd` 帮助页、`R/*.R` 源码、`tests/testthat/*.R`、`NEWS.md` 与 `vignettes/plotbb.qmd`。
状态：**稳定**＝公开且有测试与帮助页；**有限**＝公开但能力或参数受限；**内部**＝未导出、不作为 API 承诺；**未实现**＝路线图中尚未交付。

## 1. plot 对象与组合

| 能力 | 入口 | 状态 | 说明 |
| --- | --- | --- | --- |
| plot 对象 | `bbplot(data, mapping)` | 稳定 | 数据 + 全局映射 + 空图层列表 |
| 由 base 函数构造 | `as.bbplot(fun)` | 稳定 | 把 base 绘图函数当作画布 |
| 添加组件 | `+`、`bbplot_add()` | 稳定 | 单一图形内追加层/主题/标签/尺度/图例/分面 |
| 图层对象 | `bb_layer(draw, ...)` 构造，`build_layer()` 内部产出 | 稳定（0.2.5 新增） | 公共构造函数见 §5；`build_layer()` 仍为内部实现 |

## 2. 几何层与统计层

| 层 | 必要映射 | 局部 `data`/`mapping` | 状态 | 备注 |
| --- | --- | --- | --- | --- |
| `bb_point()` | `x`、`y` | 是 | 稳定 | `position = "jitter"` 可复现（`seed`），`bb_position()` 可构造位置对象 |
| `bb_line()` | `x`、`y` | 是 | 稳定 | 按数据顺序连线 |
| `bb_text()` | `x`、`y`、可选 `label` | 是 | 稳定 | 缺失 `label` 时退化为 `graphics::text` 默认 |
| `bb_segment()` | `x`、`y`、`xend`、`yend`（或 `x1`/`y1`） | 是 | 稳定 | 端点缺失即报错 |
| `bb_errorbar()` | `x` + `ymin`/`ymax`，或 `y` + `xmin`/`xmax` | 是 | 稳定 | `orientation = "y"`/`"x"`；`width` 为帽宽 |
| `bb_bar()` | `x`（`identity` 还需 `y`） | 是 | 有限 | `stat = "identity"`/`"count"`；仅竖直柱 |
| `bb_boxplot()` | `x`、`y` | 是 | 有限 | 分组箱线图，参数透传 `graphics::boxplot` |
| `bb_hist()` | numeric `x`，或离散 `x` + numeric `y` | 是 | 有限 | 按 `bb_stat_group()` 分组（离散 `x` → `group` → `col` → `fill`），逐组统一 breaks；常量 `col` 不分组；样本不足时跳过 |
| `bb_density()` | numeric `x`，或离散 `x` + numeric `y` | 是 | 有限 | 可按离散 `x` 或 `col`/`fill`/`group` 分组叠加多边形 |
| `bb_tile()` | `x`、`y`、`col` | 是 | 有限 | 热图瓦片；`fill` 优先于 `col` |
| `bb_lm()` | `x`、`y`，可选 `group` | 是 | 有限 | `se`/`level` 置信带；小组合格性不足时跳过 |
| `bb_signif()` | `comparisons` 或 `xmin`/`xmax`/`y_position` | 是 | 有限 | 支持内置检验与 `test` 参数，y 范围自动扩展 |
| `bb_grid()` | 无 | — | 稳定 | `bg = TRUE` 画在背景，否则按顺序画 |
| `bb_facet_wrap()` | 公式 | — | 有限 | `fixed`/`free`/`free_x`/`free_y`；无 `facet_grid` |
| `bb_legend()` | 无 | — | 有限 | `col`/`fill`/`pch`/`lty`/`cex`，支持外置位置 |

## 3. 映射与常量

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| `bb_aes(x, y, ...)` | 稳定 | 只捕获显式写出的映射 |
| 局部 `mapping` 覆盖全局 | 稳定 | `modifyList` 语义：同名 aesthetic 局部优先 |
| 图层局部 `data` | 稳定 | 缺省继承 plot data |
| 常量美学 | 稳定 | 层的 `...` 参数（如 `col = "tomato"`），不进尺度；`fill` 仅在 density/tile/自定义层有意义，其余图层传入即报错 |
| 常量优先于映射 | 稳定 | 由 `bb_layer_aesthetics()` 统一实现：常量直接移除该 aesthetic 的映射，不再逐层判断；`bb_hist()`/`bb_density()`/`bb_boxplot()` 此前的违规已修 |
| 逐行常量的对齐 | 稳定（0.2.5 明确） | 逐行图层中长度为 n 的常量随无效行一起过滤；summary 图层的 `col`/`fill` 是图形参数（每柱/每箱/每组），不按行对齐 |
| 映射的求值时点 | 稳定（0.2.5 明确） | 映射在 `print()` 时解析，因此 `+` 链中最后一个尺度生效；常量不参与尺度 |
| `inherit = FALSE` | 稳定（0.2.5 新增） | 仅关闭全局 mapping 继承；plot data 仍继承，除非显式提供 layer `data` |

## 4. 尺度、标签、主题与状态

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| `bb_scale_col_palette/manual/gradient` | 有限 | 只作用于 `col`；`fill` 走同一路径的有限 fallback |
| `bb_scale_pch/lty/cex_manual`、`bb_scale_cex_continuous` | 有限 | 无 `fill` 专用尺度；`lty` 目前只进图例，线类图层尚未应用映射 `lty`（0.3.0） |
| `bb_legend()` | 有限 | 连续色条为离散断点图例 |
| `bb_labs()`/`bb_title`/`bb_sub`/`bb_xlab`/`bb_ylab` | 稳定 | 后加者生效 |
| `bb_theme()` 与预设主题 | 稳定 | 仅作用于该对象，无副作用 |
| `set_bb_theme()`/`unset_bb_theme()`/`with_bb_theme()` | 稳定 | 设备级主题，`with_bb_theme()` 可嵌套且错误时恢复 |
| `print.bbplot()` 状态恢复 | 稳定 | `par()` 快照恢复，含报错与分面路径 |
| 输入验证与无效行过滤 | 稳定 | 长度校验、NA/非有限行丢弃、全无效报错 |

## 6. 未实现 / 不在本阶段

- `bb_ribbon()`、`bb_hline()`、`bb_vline()`、`bb_violin()`、`bb_smooth()`（0.4.0）
- `bb_facet_grid()`、`bb_build()`、`bb_save()`、布局组合（0.4.0/0.5.0+）
- `fill` 专用尺度与统一尺度训练（0.3.0）
- `bb_layer()` 的范围贡献限于映射的 `x`/`y` 加显式 `limits`；尺度与图例仍不自动扩展。
- `inherit = FALSE` 的语义已在 0.2.5 实现：只关闭全局映射继承，数据仍继承。
- `data = NULL` 目前只表示「继承 plot data」，尚无显式「无数据」标记（roadmap 第 79 行点名的 waiver 问题）；留待 0.3 统一输入语义时处理。

## 7. 已知限制（需在 vignette 中显式标注）

- 图层参与范围靠各自的 `bb_layer_limits()` 分支（`xend`、`ymin` 等）；自定义层不在此白名单内，需用 `limits` 声明自行计算的坐标。尺度训练与图例仍不会因自定义层扩展。
- `bb_facet_wrap()` 对显式 layer data 分面时，用与 plot data 相同的 facet 表达式在其上求值取行（支持 `~f`、`~paste(f, g)`、变换式）；表达式所需变量不全、且行数与 plot data 相同时退回按行位置取子集；两者都不满足时整层画在每个 panel 并发出 warning，不再静默。
- `+` 只表示“向单一图形添加组件”；把两个完整 `bbplot` 相加不会被静默当作叠加层——`bbplot_add.bbplot` 未定义，会报错。
